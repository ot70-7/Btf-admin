1. 创建 Mint 并一次性铸造

Mint 地址在浏览器内生成，创建后私钥不再需要。全部供应量一次性铸造到项目方钱包，之后按分配表转出。

Mint 地址（请抄写保存）

地址已存在本机浏览器，刷新不会丢；但请另行抄写一份，浏览器数据可能被清除。

2. 写入元数据

URI 指向一个公开的 JSON 文件，其中包含名称、图标和简介。可以先把本仓库的 metadata.json 与 logo 上传到任意静态托管。

3. 分配代币

按 config/project.json 中的比例与钱包地址分配。未填写地址的条目会被跳过，只处理已配置的条目。

4. 撤销权限（不可逆）

撤销 Mint Authority 与 Freeze Authority。执行后供应量永久固定，也没有任何地址能冻结用户代币。
